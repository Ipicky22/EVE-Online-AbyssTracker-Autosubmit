# EVE Online AbyssTracker Autosubmit

[English](README.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | **中文**

> 本译文未经中文母语者校对，以[英文版](README.md)为准。

自动把你在 EVE Online 中的深渊（Abyssal Deadspace）记录提交到 [Abyss Tracker](https://abysstracker.com)。
程序名为 `abyssup`。
它从不操作 EVE 客户端：只读取 EVE 写入硬盘的本地频道聊天日志，以及 Windows 剪贴板。

> **状态：开发中。** 上传功能已可用。Windows 剪贴板读取尚未在真实电脑上测试，见[验证状态](#验证状态)。

## 使用方法

1. 运行 `abyssup.exe`：页面 `http://localhost:47813` 会自动打开。
2. 选择天气、等级、舰船级别和装配，然后点击**开始会话**。
3. 第一次深渊前，复制货柜舱（`Ctrl+A`，`Ctrl+C`）。
4. 每次深渊结束后，再次复制货柜舱：本次记录会发送到 Abyss Tracker。
5. 更换星系或停靠之后，在下一次深渊前重新复制货柜舱。

记录以公开方式发布。
没有可靠货柜舱副本的记录不会发送，而是保存在 `incomplete/` 中。

## 设置（只需一次）

1. 在 `abysstracker.com/my-account/personal-access-tokens` 创建令牌。
2. 在页面中打开**设置**，粘贴令牌并保存。

不需要 EVE 开发者应用，也不需要登录角色。
EVE 必须把聊天记录写入文件（默认已开启）。
如果你的日志不在 `Documents\EVE\logs\Chatlogs`，请在**设置**中填写文件夹。

“已验证”表示用真实日志文件测试过。“推测”表示措辞来自公开的 EVE 日志解析工具，没有用该语言的真实日志测试过：
可能无法检测到深渊记录。
欢迎提供上述任一语言的本地频道日志文件，见[已知限制](#已知限制)。
德语、俄语和中文文本未经母语者校对。
发送给 Abyss Tracker 的物品名称始终为英文。

## 选项

- `-dry-run`：把记录写入程序日志，而不发送。
- `-no-open`：启动时不打开浏览器。

## 数据

位于 `%APPDATA%\abyssup\`（Linux 下为 `~/.config/abyssup/`）：
`config.json`、`names.json`（物品名称缓存）、`abyssup.log`，
以及文件夹 `pending/`、`sent/`、`incomplete/`、`rejected/`。

令牌以明文保存在你的用户配置目录中，绝不会进入本仓库。

## 工作原理

- **角色**：从最新的 `Local_<日期>_<时间>_<角色ID>.txt` 文件读取。
- **深渊的开始、结束和时长**：每次更换星系时，EVE 都会在本地频道日志中写入一行。进入深渊时，星系显示为 `Unknown`（法语客户端为 `Inconnu`）。精确到秒，不发出任何网络请求。
- **阵亡**：离开深渊后所在的星系与使用纤维时的星系不同（在克隆体中醒来）。
- **战利品**：深渊前后两次货柜舱副本之间的差异。物品名称通过公开的 EVE API（ESI）解析为类型 ID，并在硬盘上缓存。
- **天气、等级、舰船级别、装配**：取自会话设置。

## 已知限制

- 日志不会记录停靠。更换星系会丢弃已知的货柜舱并要求重新复制；但如果你**没有离开星系**就停靠，又忘记重新复制货柜舱，下一次深渊的战利品就会出错。
- 如果你的克隆体就在使用纤维的星系中，阵亡不会被检测到。
- 同一时间只支持一个角色。
- 本地频道日志中表示深渊的词（`Unknown`、`Unbekannt`、`Неизвестно`、`未知`）只在法语（`Inconnu`）上验证过。如果你所用语言的词不对，深渊记录只是不会被检测到，也不会发送任何数据。

## 验证状态

已验证：

- 用真实的法语本地频道日志检测深渊记录：角色、进入、离开、精确到秒的时长；
- Abyss Tracker 令牌可通过 `X-API-KEY` 请求头使用；
- `fits/list` 返回账号的装配及其舰船；
- 通过程序自身的上传代码发送的测试记录出现在 Abyss Tracker 上，天气、等级、舰船级别、装配、时长和战利品均正确；
- 消耗的纤维放在损失物品中发送，只被计算一次。

仍待确认：

- Abyss Tracker 只把发送的记录归入两种战利品类型：“all cans”或“Bioadaptive and some cans”。会话中的一个复选框决定归入哪一种。发送相等的容器数量即可得到前者，这一点是推测，尚未在实际上传中见到；
- Windows 剪贴板读取和通知：已编译，从未在真实的 Windows 上运行过。
